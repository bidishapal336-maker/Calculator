## Build a Calculator
A simple and user-friendly Calculator built using HTML, CSS, and JavaScript.

### Features
- Addition, subtraction, multiplication and division
- Percentage
- Clear (AC)
- Delete (DEL)
- Decimal numbers
- Real-time display
- Responsive UI
- Keyboard support
- Hover/click effects

### Technologies Used
- HTML
- CSS
- JavaScript

### How to run
1. Open this folder in VS Code.
2. Open `index.html`.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Test the calculator using the buttons or keyboard.

### Keyboard shortcuts
- 0-9: numbers
- + - * / %: operators
- Enter or =: calculate
- Backspace: delete
- Escape or C: clear
